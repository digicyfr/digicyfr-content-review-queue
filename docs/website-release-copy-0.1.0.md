# Digicyfr Content Review Queue 0.1.0 — website draft

## English

**Keep published content on a clear review schedule.** Set an explicit due date and eligible editor for a post or page. The private Tools queue groups overdue, due-today, upcoming and unscheduled work. Mark a review complete with the next date, or snooze with a reason. Action history stays with the post; reviewing does not change its public modified date. Administrators can download a filtered CSV. Free and open source under GPL-2.0-or-later.

Tested locally with WordPress 7.1, PHP 8.3.33 and MariaDB 11.4.13. Requires WordPress 7.1+ and PHP 8.3+. No automatic reminders, recurrence, public output or external service. Download the release ZIP, upload it at Plugins → Add New → Upload Plugin, and follow the README. Updates are manual.

## Polski

**Ustal jasne terminy przeglądu opublikowanych treści.** Przypisz wpisowi lub stronie konkretny termin i uprawnioną osobę. Prywatna kolejka w menu Narzędzia pokazuje treści po terminie, na dziś, nadchodzące i bez terminu. Oznacz treść jako sprawdzoną z następną datą albo odrocz ją z podaniem powodu. Historia działań zostaje przy wpisie; przegląd nie zmienia publicznej daty modyfikacji. Administrator może pobrać przefiltrowany plik CSV. Bezpłatna wtyczka open source na licencji GPL-2.0-or-later.

Przetestowano lokalnie z WordPress 7.1, PHP 8.3.33 i MariaDB 11.4.13. Wymaga WordPress 7.1+ i PHP 8.3+. Bez automatycznych przypomnień, cyklicznych terminów, treści publicznych i usług zewnętrznych. Pobierz ZIP, prześlij go przez Wtyczki → Dodaj nową → Wyślij wtyczkę i skorzystaj z README. Aktualizacje są ręczne.
